# 이상징후 등급별 SLA (초안)

> 본 문서의 시간값(60초·15분·4시간 등)과 fan-out 단계는 모두 **운영 후보값**이다. 파일럿 운영 데이터·보호자 피드백·법무 검토 결과에 따라 조정한다.
>
> 이상징후 분류는 서버 규칙 엔진(R001~R009)이 수행하며, 본 SLA는 *분류 결과를 보호자에게 어떻게 알릴지*에 대한 운영 정책이다. AI는 분류·등급 판정 주체가 아니다.

## 1. 등급 정의

| 등급 | 코드 | 설명 |
|---|---|---|
| 일반 | `info` | 참고용, 카드 표시만 |
| 주의 | `warning` | 사실 전달 + 1회 알림 |
| 긴급 | `critical` | 즉시 알림 + 미확인 시 fan-out |

## 2. 등급별 SLA

| 항목 | info | warning | critical |
|---|---|---|---|
| 보호자 카드 노출 | 즉시 | 즉시 | 즉시 |
| 푸시/알림 | ✗ | ✓ (1회) | ✓ (다회) |
| SMS | ✗ | ✗ | ✓ |
| 알림톡 | ✗ | ✓ | ✓ |
| 보조 보호자 fan-out | ✗ | ✗ | **60초 미확인 시** |
| 자동 119 신고 | ✗ | ✗ | **✗ (정책상 금지, § 06 참조)** |
| 보호자 응답 권장 시간 | 24h | 4h | **15분** |

## 3. 보호자 미확인 시 동작

### critical 알림 발송 후

```
T+0      : primary_guardian 에게 알림톡 + SMS
T+60s    : 미확인 시 secondary_guardian 전원에게 알림톡 + SMS
T+5m     : 미확인 시 primary_guardian 에게 음성 통화 시도
T+15m    : 미확인 시 partner(돌봄 파트너)에게 알림 (있을 경우)
T+30m    : 미확인 시 운영팀(내부) 알림
```

### warning 알림 발송 후

```
T+0      : primary_guardian 에게 알림톡
T+4h     : 미확인 시 카드만 강조(배지), 추가 발송 없음
T+24h    : 미확인 시 일반(info)으로 강등
```

## 4. 보호자 액션 정의

| action | 의미 |
|---|---|
| `acknowledged` | 확인 완료 (단순 인지) |
| `called` | 직접 어르신께 전화함 |
| `visited` | 직접 방문함 |
| `dispatched_119` | 보호자가 119 신고함 |
| `noted` | 메모만 남김 (알림 상태 변경 없음) |

`acknowledged` 이상의 액션이 있어야 fan-out이 중단된다.
