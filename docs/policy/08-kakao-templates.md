# 카카오 알림톡 템플릿 초안

> 본 템플릿은 **사전 심사 제출용 초안**이다. 카카오 비즈메시지 사업자(예: NHN Cloud / Bizppurio / Aligo / 인포뱅크 등) 사전 심사 결과에 따라 본문·변수·버튼이 수정될 수 있으며, 1차 통과를 보장하지 않는다.
> 변수 표기(`#{변수명}`)와 본문 길이 제한, 정보성/광고성 분류 기준은 사업자별로 상이하므로 선정 사업자의 가이드에 맞춰 재포맷한다.
> 본문 1,000자 이내, 광고성 표현 금지를 기본 원칙으로 작성하되, 정보성 분류 여부는 사업자 심사 결과로만 확정된다.
> 의료·정신건강·응급 관련 문구는 진단·추정·처방으로 오인되지 않도록 **관찰형 표현**(예: "~표현이 잦았어요")으로 작성한다.

## 템플릿 분류

| code | 등급 | 용도 |
|---|---|---|
| `T001_DAILY_SUMMARY` | info | 매일 안부 통화 요약 |
| `T002_CALL_NO_ANSWER` | warning | 통화 미응답 |
| `T003_MEAL_SKIPPED_2D` | warning | 이틀 연속 식사 미확인 |
| `T004_MED_MISSED_REPEAT` | warning | 약 누락 반복 |
| `T005_FALL_MENTIONED` | critical | 낙상 언급 |
| `T006_VITAL_EMERGENCY` | critical | 호흡곤란/가슴통증/의식혼미 |
| `T007_MOOD_CONCERN` | warning | 우울/불안 표현 반복 |
| `T008_NO_RESPONSE_48H` | critical | 48시간 미응답 |
| `T009_SECONDARY_FANOUT` | critical | 보조 보호자 fan-out |
| `T010_CONSENT_NEEDED` | info | 음성 동의 갱신 필요 |

---

### T001 — 일일 요약 (info)

```
[곁] 오늘의 안부

#{recipient_name}님, 오늘 안부 통화 잘 마쳤어요.

· 식사: #{meal_status}
· 약: #{med_status}
· 기분: #{mood_status}

자세한 내용은 곁 앱에서 확인하세요.
```

버튼: `자세히 보기` → `https://gyeot.app/guardian/dashboard`

---

### T002 — 통화 미응답 (warning)

```
[곁] 안부 통화 미응답

#{recipient_name}님께 #{attempt_count}회 전화드렸지만 받지 않으셨어요.
#{next_retry_at}에 다시 전화드릴 예정입니다.

직접 확인이 필요할 수 있어요.
```

버튼: `지금 전화하기`, `확인 완료`

---

### T003 — 이틀 연속 식사 미확인 (warning)

```
[곁] 식사 확인 필요

#{recipient_name}님이 이틀 연속 식사를 못 하셨다고 하셨어요.

· 어제: #{yesterday_meal}
· 오늘: #{today_meal}

식사 챙김이 필요한 상황일 수 있어요.
```

---

### T004 — 약 누락 반복 (warning)

```
[곁] 약 복용 확인 필요

최근 7일 중 #{missed_count}회 #{med_name} 복용을 놓치셨어요.

알람 시간 조정이나 처방의와의 상담을 고려해보세요.
```

---

### T005 — 낙상 언급 (critical)

```
[곁] 긴급 — 낙상 관련 말씀

#{recipient_name}님이 오늘 통화 중 "#{quoted_text}" 라고 말씀하셨어요.

지금 바로 확인이 필요합니다.
```

버튼: `지금 전화하기`, `119 신고하기`

> ※ 회사는 자동으로 119에 신고하지 않습니다. 보호자가 직접 판단해주세요.

---

### T006 — 호흡곤란/가슴통증/의식혼미 표현 감지 (critical)

```
[곁] 긴급 — 응급 의심 표현 감지

#{recipient_name}님이 오늘 통화 중 "#{quoted_text}" 라고 말씀하셨어요.

통화 시각: #{call_time}
응급 여부 판단과 대응(직접 확인·119 신고 등)은 보호자께서 결정해 주세요.
```

버튼: `지금 전화하기`, `119 신고하기`

> ※ 회사는 응급 여부를 확정하거나 자동으로 119에 신고하지 않습니다. 통화에서 관찰된 표현을 그대로 전달하는 알림입니다.

---

### T007 — 정서적으로 가라앉은 표현 반복 (warning)

```
[곁] 최근 통화 표현 안내

최근 2주간 #{recipient_name}님과의 통화에서 기분이 가라앉은 듯한 표현이 반복적으로 관찰됐어요.

직접 안부를 여쭙거나, 필요하시면 가까운 정신건강복지센터 상담(국번없이 1577-0199) 안내를 함께 고려해 보세요.
```

> ※ 본 알림은 진단이나 정신질환 가능성을 의미하지 않습니다. 통화에서 관찰된 표현 패턴을 보호자께 전달하는 정보성 알림입니다.


버튼: `지금 전화하기`, `확인 완료`
