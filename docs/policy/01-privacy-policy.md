## 1. 수집 항목

| 주체 | 항목 | 수집 방법 |
|---|---|---|
| 보호자(가입자) | 이름, 휴대전화번호, 이메일, 비밀번호(해시) | 회원가입 폼 |
| 어르신(피돌봄자) | 이름, 생년월일(선택), 전화번호, 통화 시간대, 등록 약물 | 보호자 입력 |
| 어르신(통화 시) | 음성 녹음, 음성→텍스트 transcript, 분류된 응답값(enum) | AI ARS 통화 |
| 자동 수집 | 접속 IP, User-Agent, 통화 메타데이터(시작/종료/길이) | 시스템 로그 |

## 2. 수집 목적

- 안부 확인 통화 발신 및 결과 보호자 전달
- 이상징후 알림 발송
- 약 복용 일정 관리 보조
- 서비스 품질 개선 (분류 모델 평가 — **개인 식별자 분리 후**)

## 3. 보유 기간 (후보값 — 법무 검토 후 확정 필요)

아래 수치는 모두 *기준 후보값*이며, 통신비밀보호법·개인정보보호법·전자상거래법 등 관련 법령 검토와 사업적 필요성을 함께 고려해 최종 확정한다.

| 데이터 | 보유 기간(후보) | 비고 |
|---|---|---|
| 회원 정보 | 회원 탈퇴 시까지 | 탈퇴 후 30일 유예 후 파기(후보) |
| 통화 녹음 (mp3) | **90일(후보)** | 이후 자동 삭제. 실제 기간은 법무 검토 및 분쟁 대응 필요성에 따라 재조정 가능 |
| 통화 transcript / 분류 결과 | **2년(후보)** | 이상징후 추세 분석용 |
| 이상징후 알림 / 보호자 액션 로그 | **3년(후보)** | 책임 추적 |
| 결제 / 세금 관련 | 5년 | 법정 보유 |

## 4. 제3자 제공 / 처리 위탁

> 아래 수탁자 목록은 **현재 검토 중인 후보**이며, 실제 계약·고지 대상은 사전 검증 단계(통신/AI 사업자 선정)가 끝난 뒤 확정된다.

| 수탁자(후보) | 위탁 업무 | 제공 항목 |
|---|---|---|
| 음성 통화 인프라 사업자 (예: Twilio 등 — 한국 발신/수신 가능 여부 사전 검증 필요) | 음성 통화 발신/녹음 | 어르신 전화번호, 통화 시각 |
| 음성/언어 모델 제공자 (예: OpenAI 등) | 실시간 음성 대화 처리, 전사 | 음성 스트림, transcript |
| 카카오 알림톡 사업자(선정 예정) | 알림 발송 | 보호자 전화번호, 알림 내용 |
| 이메일 발송 사업자(선정 예정) | 이메일 알림 | 보호자 이메일 |

> **국외 이전**: 위 수탁자 중 일부는 국외(예: 미국)에 데이터센터를 둘 수 있다. 최종 사업자 확정 후 국외 이전 사실·국가·항목·보유기간을 별도 고지하고 동의를 받는다.

## 5. 정보주체 권리

- 보호자: 본인 정보 조회/수정/삭제 요청 가능 (앱 내 또는 support@…)
- 어르신: 보호자 또는 본인이 음성/서면으로 요청 가능

## 6. 파기 절차 (후보)

- 회원 탈퇴 → 30일 후 자동 hard delete (후보 일정)
- 녹음 파일 → 보유 기간(후보 90일) 경과 시 Storage 자동 만료
- 백업본 → 60일 보관 후 파기(후보)

## 7. 안전조치

- 전송 구간: TLS 1.2+
- 저장: DB 암호화(at-rest), Storage 암호화
- 접근 통제: RLS 기반 가족 단위 격리, 관리자 접근 감사 로그
- 음성 녹음 청취: 보호자 본인 인증 + 단기 presigned URL(예: 7일 — 후보)
