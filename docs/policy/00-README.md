# 운영 정책 문서 (Care Call)

이 폴더는 **곁(Gyeot) Care Call** 서비스의 운영/법적 정책 **초안 모음**입니다.
모든 문서는 **초안(draft)** 상태이며, 본문에 등장하는 수치(보존 기간, SLA 시간, 동의 갱신 주기 등)와 스크립트 문구는 **모두 후보 값**입니다. 실제 서비스 적용 전 다음을 거쳐야 합니다.

1. 사내 검토 (PM/Eng/Care)
2. 외부 법무 검토 (개인정보보호법, 통신비밀보호법, 의료법, 응급의료법 등 관련 법령)
3. 카카오 비즈메시지 사업자 템플릿 사전 심사 (통상 5~7영업일, 실제 일정·반려 가능성은 사업자별 상이)
4. KCA 발신번호 사전 등록 및 한국 통신 사업자/번호 임대 가능 여부·절차 사전 확인
5. 한국 고령 사용자 대상 음성 UX 청취 테스트 및 실통화 품질 파일럿

| # | 파일 | 목적 |
|---|---|---|
| 01 | `01-privacy-policy.md` | 개인정보 처리방침 |
| 02 | `02-voice-consent.md` | 어르신 음성 동의 절차 |
| 03 | `03-call-disclosure.md` | 통화 시작 의무 고지문 |
| 04 | `04-llm-guardrails.md` | 금칙어 / 허용 표현 가이드 (LLM system prompt) |
| 05 | `05-anomaly-sla.md` | 이상징후 등급별 SLA |
| 06 | `06-emergency-policy.md` | 119 / 응급 연계 정책 |
| 07 | `07-data-retention.md` | 데이터 보존 / 파기 정책 |
| 08 | `08-kakao-templates.md` | 카카오 알림톡 템플릿 초안 |

> **원칙**: 본 서비스는 의료기기/의료행위가 아니다. 모든 문구는 "보호자에게 사실을 전달"하는 형태이며, 진단/처방/치료를 암시하는 표현은 금지한다.
>
> **AI 역할 한정**: 질문 순서·위험 분류·이상징후 판정은 모두 서버 측 상태머신과 규칙 엔진이 결정한다. AI(LLM/음성 모델)는 *결정된 질문을 한국어로 자연스럽게 발화하고, 응답을 전사·구조화하는 보조 역할*에 한정되며, 의료·정신건강·응급 판단의 최종 주체가 아니다.

## 12. 사전 검증 없이 확정하면 안 되는 항목

다음 항목은 본 정책 폴더의 어떤 문서에도 *최종 확정형*으로 기술되어서는 안 되며, 실제 운영 적용 전 사전 검증·검토가 반드시 선행되어야 한다. 본 폴더의 관련 문구는 모두 **후보안/초안**으로만 취급한다.

| # | 항목 | 필수 검증/확정 절차 | 관련 문서 |
|---|---|---|---|
| 1 | 한국 발신 번호 / 발신자 표시 / 통신 사업자 전략 | 사업자별 한국 발신 가능 여부·번호 임대 가능 여부·KCA 사전 등록 절차 확인, 실통화 파일럿 | `HANDOFF.md` § 사전 검증 단계 |
| 2 | 한국어 음성 청취 품질 / 응답 지연 | 한국 고령 사용자 대상 청취 테스트, 망별 실통화 품질 측정 | `03-call-disclosure.md`, `04-llm-guardrails.md` |
| 3 | 녹음 / transcript 보관 정책 (기간·범위) | 통신비밀보호법·개인정보보호법 법무 검토 | `01-privacy-policy.md` § 3, `07-data-retention.md` |
| 4 | 응급 / 정신건강 관련 알림 문구 | 의료법·응급의료법 관점의 법무 검토, 의료/약사 자문 | `04-llm-guardrails.md`, `06-emergency-policy.md`, `08-kakao-templates.md` (T005·T006·T007) |
| 5 | 약물 주의사항 / 상호작용 데이터 출처 | 식약처 등 공식 출처 인용 가능성·라이선스·갱신 주기 확인, 출처 표기 정책 확정 | (별도 약물 데이터 정책 문서로 분리 예정) |
| 6 | 보호자 / 어르신 동의 구조 (동의 주체·갱신 주기·철회 절차) | 통신비밀보호법·개인정보보호법 관점 법무 검토 후 모델 확정 | `02-voice-consent.md` |
| 7 | 카카오 알림톡 템플릿의 정보성 분류 통과 여부 | 비즈메시지 사업자 사전 심사 결과, 반려 시 재작성 | `08-kakao-templates.md` |
| 8 | 국외 이전(수탁자) 항목·국가·고지·동의 절차 | 최종 사업자 확정 후 별도 고지·동의 흐름 설계 및 법무 검토 | `01-privacy-policy.md` § 4 |

위 항목 중 어느 하나라도 검증·확정이 끝나지 않은 상태에서 실제 어르신을 대상으로 한 운영(실통화·실알림 발송)은 진행하지 않는다.
